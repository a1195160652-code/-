# 活动主KV项目

用于集中管理活动主视觉（Key Visual）的需求、素材、设计源文件和交付版本。

当前阶段：项目空间初始化，尚未开始设计；活动名称、主题文案、尺寸及交付时间待确认。

## 目录

| 路径 | 用途 |
| --- | --- |
| assets/ | 标志、插画、图片等素材及来源记录 |
| source/ | PSD、AI 等可编辑设计源文件 |
| exports/ | 按版本保存的预览图与正式交付文件 |
| CHANGELOG.md | 版本与修改记录 |
| DELIVERY.md | 交付规格、命名和验收清单 |

## 开始使用

1. 在下方补齐需求，确认后再开始设计。
2. 将可公开的素材放入 assets/，填写素材来源。
3. 在 source/ 保存设计源文件；每轮评审导出到 exports/ 对应版本目录。
4. 更新 CHANGELOG.md，交付前按 DELIVERY.md 核对。
